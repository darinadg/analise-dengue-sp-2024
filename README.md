# Análise das notificações de dengue em São Paulo — 2024

Projeto acadêmico de análise exploratória de dados utilizando Python, Pandas, NumPy e Matplotlib.

## Objetivo

Analisar a distribuição mensal das notificações de dengue em residentes de São Paulo durante 2024.

## Fonte dos dados

Ministério da Saúde — Portal de Dados Abertos do SUS:
https://dadosabertos.saude.gov.br/dataset/arboviroses-dengue

## Tecnologias utilizadas

- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab
